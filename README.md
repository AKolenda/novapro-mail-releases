# NovaPro Mail downloads

Download NovaPro Mail for Windows from the [latest release](https://github.com/AKolenda/novapro-mail-releases/releases/latest).
Choose the `.exe` installer. The `.yml` and `.blockmap` files are used by the app's updater.

Install the signed release once, then sign in with your NovaPro account.
The app checks for updates at startup and every four hours and downloads them
automatically. Save your drafts, then choose **Restart to update…** in the
Windows tray menu to install a downloaded update.

Existing manual installations need this installer once to enable automatic
updates. Closing the mail window keeps the app running in the tray.

This repository contains installer downloads only. Application source remains
private. You do not need a GitHub account to download or update NovaPro Mail.
